# IT Portfolio

A responsive, framework-free portfolio site designed for GitHub Pages.

## Make it yours

Search `index.html` for the sample details and replace them with your own:

- Name, location, availability, and professional introduction
- Skills, project descriptions, roles, dates, and education
- Email address and GitHub / LinkedIn profile URLs
- Page title and meta description

The project illustrations are built with HTML and CSS, so no image assets or build tools are required. Google Fonts are loaded from the web; the site uses system fallbacks if they are unavailable.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Push these files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your publishing branch and the **/(root)** folder, then save.

GitHub Pages will publish the static site at the URL shown in the Pages settings.
